Windows x64 / ARM64 提供安装版和便携版；Android 提供三种 ABI 与通用 APK；macOS 提供未做 Developer ID 签名和 Apple 公证的测试 ZIP；Linux x64 提供实验性 .deb 与发行版中立的 tar.gz。全部平台构建及产物校验通过后发布，校验和见 SHA256SUMS.txt。
构建通过不代表所有设备兼容性问题已完成实机验证，已知问题见 README。

## 本版要点

### 新材质：柔光玻璃（Beta）
设置 → 外观 → 材质现在有两种选择。默认的 **MD3E** 就是原来的样子（原名「伪液态玻璃」）；**柔光玻璃**换成 HyperOS 4 风格：

- 菜单、弹窗、底部弹层、提示、底栏、音乐条、播放页都换成模糊材质
- 图标、字重、配色、页面转场和滚动回弹一起调整
- 顶栏渐变模糊，tab、分段选项、设置滑杆和音乐条都能拖动

已在 Windows 和 Android 上实际使用过。macOS、Linux 上的柔光玻璃：⚠️ 未实机测试，需测试。

从柔光玻璃切回 MD3E 后，图标要重启应用才恢复。

### 自定义快捷键
设置 → 关于 → 键盘快捷键现在可以改键，也可以开启全局快捷键（窗口不在前台时控制播放）。全局快捷键支持 Windows 和 macOS，Linux 暂不支持。⚠️ 全局快捷键未实机测试，需测试。

### Windows 系统托盘
设置 → 启动 → 关闭时最小化到托盘，默认关闭。开启后关闭窗口音乐继续播放，可从托盘恢复或退出。⚠️ 托盘菜单未完整实机测试，需测试。

### 登录修复
修复 Windows 上登录成功后又回到登录页、反复循环的问题：Spotify 拒绝第一次取令牌时不再清空登录状态，会先重试，再改由登录页自己请求，失败时显示原因。⚠️ 未用受影响的账号实机测试，需测试。如果仍然登录失败，请在反馈里附上 `%TEMP%\flutify.log`。
