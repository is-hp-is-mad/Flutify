Windows x64 / ARM64 提供安装版和便携版；Android 提供三种 ABI 与通用 APK；macOS 提供未做 Developer ID 签名和 Apple 公证的测试 ZIP；Linux x64 提供实验性 .deb 与发行版中立的 tar.gz。全部平台构建及产物校验通过后发布，校验和见 SHA256SUMS.txt。
构建通过不代表所有设备兼容性问题已完成实机验证，已知问题见 README。

## 本版要点

### Android 桌面小组件
新增 4 款基于 Jetpack Glance 的原生桌面小组件，支持系统小组件选择器与应用内设置直接添加（设置 → 桌面小组件）：
- **黑胶唱片 / 专辑卡片（AlbumCard）**：模拟黑胶唱机排版与专辑封面
- **大封面（Cover）**：聚焦艺术封面的极简卡片
- **精简播放卡片（NowPlaying）**：紧凑展示当前曲目信息与控制按键
- **待播列表（UpNext）**：显示当前播放及下一首待播曲目
- 支持提取封面主色调自适应背景与冷启动秒级渲染，与应用内播放状态双向实时同步。

### HyperOS 柔光玻璃视觉系统升级
深入对齐小米澎湃 OS（Xiaomi HyperOS）设计语言规范与质感：
- **主页柔光胶囊 Tab**：升级为正统 HyTextTabs 柔光胶囊分段规范，支持状态栏穿透模糊
- **字重与排版精细化**：全工程各层级标题字重对齐小米 MiSans w600 规范，消弭粗重压迫感
- **顶栏无缝衔接**：桌面端连续渐变模糊，消除吸顶接缝与下层内容英文穿透
- **触感与动效**：播放控制条接入 Pressable 触感反馈与材质微透光渲染

### Android 悬浮底栏
- 柔光玻璃底栏升级为随滚动智能收放的悬浮胶囊：向下滚动阅读浏览时自动收起以提供沉浸视野，回到顶部时平滑展开回弹
- 惯性快速滚动中亦保持可交互能力

### 移动端 iOS 风格快捷曲目菜单
- 移动端歌曲列表「更多」操作弹出层重构为 iOS 风格快捷分组面板，高频操作一键直达，分组排版更清晰直观

### 动效与构建适配
- **歌词动效**：重构歌词卡片与翻译胶囊展开/收起过渡动效，交互更顺滑
- **构建适配**：全面适配 Android Gradle Plugin 9.0 与 Kotlin 2.x DSL 规范

## 已知问题
