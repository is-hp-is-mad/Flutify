# 下一首预加载

Android 使用的播放 Provider 与 DRM 音源共同预取下一首；这些共享代码在其他平台上也保留同一契约。

- 当前歌曲可起播不代表已完整下载。`LoadedAudio.downloadComplete` 是可选的整首下载完成信号，普通渐进流仍用 `stream.done`；没有后台下载时为 null。
- 当前下载完成后才预取，不与当前歌曲抢起播带宽；暂停不会丢失完成通知，切歌、丢弃会话或销毁后忽略旧结果。
- 同时只运行一次后台预取。队列添加、移除、重排、远程队列更新及循环设置变化后跟随最新目标，避免重复请求；播客、单曲循环和本首结束后停止不预取不同歌曲。
- 随机列表循环提前准备下一轮顺序，预取与实际切歌共用该顺序。
- DRM 音源保留下一首的已解析信息，并合并进行中的预取和点播。切歌可接用同一下载，不重复请求曲目播放信息、HLS 或重写同一缓存文件。
- 缓存移动、文件或完成标记丢失、下载失败时重新加载。复用仍检查 Web 登录前提；不绕过登录或 DRM 授权。
- 预取错误不会变成当前播放错误；正式切歌仍按原播放流程重试。后台媒体会话、暂停/取消、Connect 控制权和既有播放器动画保持独立。

这不是无缝播放引擎：DRM 授权、播放器换源及网络状态仍可能造成间隔。

回归入口：`test/next_track_prefetch_test.dart`、`test/eme_prefetch_test.dart`，并与 `background_playback_transition_test.dart`、原生 DRM、媒体控制、睡眠定时及缓存测试一起运行。测试使用受控下载与合成音频，不代替真实账号的整曲连续播放测量。
