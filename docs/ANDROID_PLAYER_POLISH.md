# Android 播放器与歌词更新

本次更新基于上游 `9f65921` 整理。已经合并的搜索分页、艺人目录、播放器详情导航
和旧版展开动画不重复引入；保留上游省电模式、帧率限制和桌面导航/鼠标交互。
没有新增依赖，没有改变认证、DRM、签名配置、发布流程或应用版本号。

## 用户可见变化

### 播放队列连续转场

- 详情 → 队列：同一个封面和控制区收拢到卡片，队列轻微上移并淡入；返回时
  列表先完整保留到淡出结束，封面展开，不再立即替换成空组件。
- 歌词 ↔ 队列：共享同一张控制卡片，先完成内容交接。队列入场完成后，卡片以
  420ms 非线性曲线自动收到底栏；竖屏列表随之向下扩展，顶部与滚动锚点保持。
  从已收起的歌词页切入队列直接保留收起状态，不多做一次展开/折叠。
- 点击唤醒卡片后，空闲 3.5 秒重新收起；持续触摸、弹窗、后台及无障碍导航
  沿用原保护策略。入场期间主动操作取消立即折叠，改为操作结束后计空闲时间。
- 队列离场后保留滚动状态，但不可点击、聚焦或被无障碍朗读；列表拖拽排序、
  移除、点歌等操作仍由原组件负责，过渡层不触发播放操作。
- 内容交叉淡入时，两侧内容及翻译工具都暂不接收点击、焦点或无障碍操作，
  完全到位后才交接，避免点击仍可见的旧内容却误切歌/跳歌词；底栏始终可反向切换。
- 参考本地 Apple Music 6.5.3 拆解：`player/fragment/v0.java` 的三视图共用封面、
  内容淡入淡出 500ms，以及 `utils/E.java` 的 `(0.25, 0.1, 0.25, 1)` 曲线。
  `p070d9/f.java` 另显示原生共享元素为 300ms、`(0.2, 0.06, 0, 1)`；本项目
  将涉及队列的共享几何与内容统一为 500ms，避免两组组件先后到位。轻微上移是
  对现有 Flutter 布局的适配，不声称与 Apple 私有实现逐像素一致。
- 验收：全路径中间帧/快速反向、退出保留列表、滚动位置、闲置恢复、无障碍和
  减弱动效测试，再验证真实队列操作及 Android Profile 预览；不修改桌面队列。

### 详情页控制组件恢复与连续收拢

- 详情页恢复原来的 60dp 白色圆形播放按钮、34dp 深色图标、进度条下方的时间标签，
  以及展开的控制/底栏间距；歌词终态继续使用紧凑玻璃卡片。
- 点击歌词后，封面、标题、进度条、时间和按钮由同一非线性进度驱动，连续改变
  位置、大小、间距和按钮颜色，而不是切换两套控件。时间标签移动到进度条两侧。
- 保留一个真实可拖动的进度条和一组播放按钮，中途反向不重置组件或播放状态；
  卡片收起、点击导航、减弱动效、大字体及非 Android 行为保持可用。
- 验收顺序：终态及中间帧回归 → 播放器/歌词完整回归 → 模拟器合成歌曲录屏 →
  正式入口 ARM64 Release 构建 → 同签名、递增版本号覆盖安装，不卸载或清数据。

### 封面、歌名和艺人使用同一个转场进度

- Android 全屏播放器在封面视图与内嵌歌词之间切换，不新增路由。
- 640ms、`Cubic(0.22, 0.8, 0.22, 1)` 驱动单一进度。封面用 `Rect.lerp`
  同时插值位置和尺寸，沿直线移动，不再提前缩小后滑入。
- 「直线」描述空间路径，时间仍有缓动；没有弹簧、过冲或回弹。
- 标题/艺人的位置和可用宽度直接使用同一进度，不再延迟启动或向右移动后折返。
- 标题字号连续变化至原字号的 0.65，艺人字号不变；固定标题行高并保持文字及点击
  容器的元素身份，避免字号跳变、跑马灯重建和艺人行抖动。
- 中途反向从当前进度继续；减弱动效时使用最终布局。

### 歌词控制卡片与点击行为

- 进入歌词后，控制卡片在底部展开；3.5 秒无操作后向下收起上部内容，保留底栏。
- 手指明显下划时展开，上划时主动收起；折叠状态下横向拖动、单纯按下或取消手势
  不误展开。每个指针独立累计位移，同一次手势改变方向也能正确响应。
- 收起采用 420ms、`Cubic(0.32, 0.72, 0, 1)` 的非线性进度，快速起步、柔和收尾；
  同向连续移动不重启动画，中途反向从当前进度衔接，避免位置跳变。
- 已展开状态持续按住时不因计时器收起；弹出目的地菜单、后台及无障碍导航仍保留
  原保护策略，减弱动效时直接使用目标布局。
- 收起部分不参与点击、焦点或语义树；底栏设备、歌词、队列入口仍能首次点击响应。
- 设备按钮保持至少 48dp 点击目标，但不再吞掉整片空白。空白点击只展开卡片，
  不误开设备选择，也不穿透到歌词触发跳转；折叠底栏中间空白的点击在释放后识别，
  不与上划折叠或设备、歌词及队列按钮的独立操作混淆。
- 点击封面返回歌曲信息；点击标题/艺人打开专辑及艺人目的地菜单，收藏保持独立。
- 保留已有播放器展开/收起及返回历史；适配窄屏、横屏、安全区和大字体。

### Android 歌词和背景

- 原生小位图背景在工作线程合成，通过同一 Flutter 纹理跨播放器视图复用，
  封面切换时淡入，快速切歌保留最新待处理图片，渲染过慢时退为静态背景。
- 42ms 帧间隔约为 24fps，低于全局帧率限制设置的最低 30fps；不修改全局帧率控制。
- 隐藏、进入后台、省电或减弱动效时停止持续渲染。生命周期停用直接通知原生端，
  不依赖后台可能不再到来的 Flutter 帧；延迟创建也不能恢复过期的活动状态。
- 静态状态下换图直接采用最新封面，结束未完成的淡入，避免动画时钟停止后卡在旧图。
- 正常可见状态下，暂停歌曲仍保留缓慢背景流动；桌面端的液态背景已与此对齐，仅在
  减弱动效或省电模式下停止。暂停/缓冲时，歌词间奏点会冻结。
- Android 行同步歌词采用 30sp 基础字号、8% 上方锚点、逐行位移级联及四边渐隐，
  非当前行使用透明度和缩放，不新增整屏模糊。
- 手动浏览在触摸与惯性滚动均结束、再空闲 5 秒后恢复跟随；继续交互会重新计时。
- 仅明确的前奏或空白间奏达到 7 秒时显示呼吸点；间奏退出与移除占位保持位置连续。
- 非 Android 渲染保留鼠标指针、逐行重绘隔离、模糊和原有布局。

这是一份独立实现，不包含 Apple 私有代码、图片、网格表或 TTML 引擎。
现有数据没有逐词时长，不生成伪造的逐词高亮。

### 翻译和后台播放

- 对歌词来源的拆行译文进行对齐，保留空行、时间戳和间奏边界。
- 已有部分译文时继续显示可读内容；后备来源只在增加覆盖且不丢失已有译文时替换。
  取消、切歌、清缓存或后备失败不能恢复过期状态或抹掉现有内容。
- 歌词返回/重新挂载后立即同步共享翻译控制器的缓存状态，无需等待新通知。
- 将播放意图与引擎换源时的短暂暂停分开，使自动下一首和单曲循环期间的 Android
  媒体会话保持有效；用户暂停、睡眠定时、队列结束或最终失败仍正常释放。
- 共用的播放 Provider、媒体控制同步与翻译修复也作用于其他平台；不是所有改动都
  仅发生在 Android 文件中。远程 Connect 对媒体按键的接管顺序保持不变。

## 验证与复验

合成曲目、fake 服务和受控时钟覆盖几何连续性、快速反向、元素身份、点击边界、
计时与生命周期、翻译补缺及播放取消竞态。桌面光标、省电和原有歌词测试一起复验。

```sh
flutter pub get
flutter analyze --no-pub --no-fatal-infos lib test
flutter test --no-pub --concurrency=2
flutter build apk --debug --no-pub --target-platform android-arm64 --target lib/main.dart
git -c core.whitespace=cr-at-eol diff --check
```

`tool/player_lyrics_preview.dart` 使用合成歌曲、歌词和可跳转的预览时钟，供 Android
离线观察进入/返回、卡片收起和间奏效果；不是正式应用入口，不能覆盖日常安装。
预览仅在专用模拟器上运行：先在本机通过
`python3 -m http.server 8766 --bind 127.0.0.1 --directory assets/brand`
提供项目图标，再对该模拟器执行
`adb -s <emulator-id> reverse tcp:8766 tcp:8766`，最后使用
`flutter run -d <emulator-id> --profile --target tool/player_lyrics_preview.dart`。
结束后停止本地服务并移除该模拟器的端口映射；不依赖真实账号或第三方封面服务。

测试和构建结果、运行时验证边界会随 PR 描述记录；不把 widget 采样或模拟器录屏
等同于真机 GPU 帧率、真实账号播放、DRM 或在线翻译服务验收。
